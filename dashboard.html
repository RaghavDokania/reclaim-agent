Diagnosis Method Breakdown

Method Count Rate Approach
Keyword Rules 60 80% Fast, deterministic, no network calls
LLM Escalation 15 20% Ambiguous cases where rules conflict
Misclassifications 5 6.7% Edge cases, held for review

The classifier is two layers. Keywords handle clear cases fast. Ambiguous cases—where error text matches multiple categories—escalate to Groq's LLM with confidence scoring. If the LLM returns low confidence, the payment waits for a human. Any LLM failure falls back to error codes. A diagnosis is always produced.
