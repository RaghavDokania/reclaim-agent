The two-layer classifier starts with rules for fast, explainable decisions. When keyword matching is ambiguous (both high and low confidence matches), the ambiguous case escalates to Groq's LLM for a final diagnosis with confidence scoring. Any LLM failure falls back to error_code-based prediction.

Policy Comparison

Offline analysis comparing four policies on the same batch, using identical success-rate assumptions. The gated agent recovers less on its own authority because it refuses low-confidence and high-value payments.

Policy Recovered Amount Attempts Held Held Amount
do_nothing 0 ₹0 0 0 ₹0
naive_retry_all 37 ₹4,99,549 131 0 ₹0
agent_routing_ungated 46 ₹6,22,121 118 0 ₹0
agent_gated (ships) 26 ₹3,20,872 77 29 ₹4,85,827

Key insight: The ungated agent recovers 16% more than naive retry, proving the routing strategy works. With gates on, the shipped agent recovers less on its own authority, but holds ₹4.86L for human sign-off — compliance-first design. This two-number framing is critical: recovery + held = full risk picture.
